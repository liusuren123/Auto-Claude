### 运行踩的两个环境坑（都不是代码问题）
1. **`ELECTRON_RUN_AS_NODE=1` 被 CLI shell 环境注入** → electron.exe 退化成普通 Node，`electron` 模块解析到 npm 包（默认导出是字符串路径），报
   `SyntaxError: The requested module 'electron' does not provide an export named 'BrowserWindow'`。
   特征：`electron.exe --version` 打印的是 **Node 版本**而不是 Electron 版本。
   解决：`env -u ELECTRON_RUN_AS_NODE -u NODE_OPTIONS ./node_modules/electron/dist/electron.exe .`（正确应为 `v40.0.0`）。
2. **无 GPU 的虚拟机** → GPU 进程反复 `exit_code=-1073741819 (0xC0000005)`，最终 `FATAL: GPU process isn't usable. Goodbye.` 退出码 3。
   解决：加 `--disable-gpu --disable-gpu-compositing --no-sandbox`，走软件渲染即可正常起窗。
